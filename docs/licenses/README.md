# Supplemental license sources

The Verovio 4.2.0 npm artifact contains no COPYING files. The retained texts
were obtained unchanged from official release commit
`8a772f537472c283d60b7e3c63c242344949cddf` (`version-4.2.0`):

- `verovio-COPYING`: <https://github.com/rism-digital/verovio/blob/version-4.2.0/COPYING>
- `verovio-COPYING.LESSER`: <https://github.com/rism-digital/verovio/blob/version-4.2.0/COPYING.LESSER>

These are license texts, not complete corresponding source or resource-license
inventory. Review upstream fonts/resources before binary redistribution.

`fast-MIT.txt` is the unchanged Microsoft FAST MIT notice from official commits
`7f8e2db596277e78fddd88a6c99444ca64f5e771` (fast-element 1.13.0,
fast-foundation 2.49.6, fast-react-wrapper 0.3.24) and
`c49a98f7f1bd8e167b0b7a96a181990f9a675f34` (fast-web-utilities 5.4.1).
Both texts are identical. These are the exact npm publication gitHead values.

`window-function@2.1.0` declares MIT and its README preserves the copyright
`(c) 2015 Ricky Reusser. MIT License`, but its publication commit
`b0bc50c668933d87780908b6a3cbba888dc4b9fd` has no standalone LICENSE. Do not
substitute a newer version's changed licensing text without reviewing it.

`@shren/typed-event-emitter@1.1.1` declares MIT but has no standalone license
file in npm. Inspected official HEAD `e2f262b97ea5f42027dbddf1399d42556bfab170`
also returned no LICENSE. The release collector preserves package metadata
and README and warns rather than inventing a copyright statement.
